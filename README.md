# ระบบเผยแพร่ข่าวสารและกิจกรรมของคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ มก.ฉกส.

เว็บไซต์สำหรับเผยแพร่ข่าวสารและกิจกรรมของคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร พัฒนาด้วย React สำหรับส่วนเว็บไซต์และระบบจัดการ Node.js สำหรับ API และ MySQL สำหรับจัดการฐานข้อมูล

---

## 📋 ข้อกำหนดเบื้องต้น (Prerequisites)

- Node.js
- npm
- MySQL
- XAMPP หรือโปรแกรมสำหรับจัดการฐานข้อมูล

---

## 🚀 เริ่มต้นติดตั้งโปรเจกต์ (Installation)

### 1. ติดตั้ง Dependencies

เข้าไปยังโฟลเดอร์ของแต่ละโปรเจกต์ และใช้คำสั่ง

```bash
npm install
```

### 2. เริ่มต้นใช้งาน

สำหรับ Frontend สามารถใช้คำสั่ง

```bash
npm run dev
```

สำหรับ Backend ให้ใช้คำสั่งตามที่กำหนดใน `package.json`
