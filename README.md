# ระบบเผยแพร่ข่าวสารและกิจกรรมของคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ มก.ฉกส.

เว็บไซต์สำหรับเผยแพร่ข่าวสารและกิจกรรมของคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร พัฒนาด้วย React สำหรับส่วนเว็บไซต์และระบบจัดการ Node.js สำหรับ API และ MySQL สำหรับจัดการฐานข้อมูล

---

## 📋 ข้อกำหนดเบื้องต้น (Prerequisites)

- Node.js
- npm
- MySQL
- XAMPP หรือโปรแกรมสำหรับจัดการฐานข้อมูล

---

## 🚀 เริ่มต้นติดตั้งโปรเจกต์ (Installation)

### 1. ติดตั้ง Dependencies

เข้าไปยังโฟลเดอร์ของแต่ละโปรเจกต์ และใช้คำสั่ง

```bash
npm install
```

### 2. เริ่มต้นใช้งาน

สำหรับ Frontend สามารถใช้คำสั่ง

```bash
npm run dev
```

สำหรับ Backend ให้ใช้คำสั่งตามที่กำหนดใน `package.json`

---

## 📁 โครงสร้างโปรเจกต์โดยสังเขป (Project Structure)

```text
├── API-MANAGE-ACTIVITY/          # Backend และ API
│   ├── src/
│   │   ├── config/               # การตั้งค่าระบบ
│   │   ├── features/             # การทำงานของแต่ละส่วน
│   │   └── middlewares/          # การตรวจสอบและจัดการคำขอ
│   └── package.json
│
├── KUSE-ACTIVITY/                # เว็บไซต์สำหรับผู้ใช้งานทั่วไป
│   ├── public/
│   ├── src/
│   │   ├── components/           # ส่วนประกอบที่ใช้ร่วมกัน
│   │   ├── pages/                # หน้าต่าง ๆ ของเว็บไซต์
│   │   └── style/                # ไฟล์ CSS
│   └── package.json
│
└── KUSE-ADMIN-ACTIVITY/          # ระบบสำหรับผู้ดูแล
    ├── public/
    ├── src/
    │   ├── components/           # Component ที่ใช้ร่วมกัน
    │   ├── modals/               # หน้าต่าง Modal
    │   ├── pages/                # หน้าจัดการข้อมูล
    │   ├── utils/                # ฟังก์ชันที่ใช้ร่วมกัน
    │   └── style/                # ไฟล์ CSS
    └── package.json
```
